# apron.chat

Website for the [Apron Chat Protocol](https://github.com/shazow/apron).

Plain static files, no build step:

- `index.html`: the landing page (inline CSS, no JavaScript).
- `llms.txt`: a summary for LLMs, per [llmstxt.org](https://llmstxt.org/).
- `apron.png`, `apron-og.png`: mascot art from [shazow/apron/art](https://github.com/shazow/apron/tree/main/art).

Preview locally with `python3 -m http.server` and open http://localhost:8000.
