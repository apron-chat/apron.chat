Apron Chat Protocol

A simple chat protocol for small, trusted groups. A server in ~100 lines. A bot in a few.

v8 · beta, core stable · MIT

1.The Protocol

JSON frames over a WebSocket. The server is the authority. No federation. A small core, and optional capabilities that each come with a fallback.

<-{"method": "server", "params": {"apron": 8, "auth": ["guest"]}}
->{"method": "auth", "id": "c1", "params": {"scheme": "guest", "name": "Ada"}}
<-{"id": "c1", "result": {"you": {"user_id": "guest_1234", "name": "Ada"}}}
->{"method": "message", "id": "c2", "params": {"body": {"text": "Hello"}}}
<-{"method": "message", "params": {"room_id": "general", "from": {"user_id": "guest_1234"}, ...}}
<-{"id": "c2", "result": {"message_id": "1724803200042"}}
