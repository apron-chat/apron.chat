Apron Chat Protocol

Apron is a minimal protocol for self-hosted chats. Simple enough to write a server in ~100 lines, powerful enough for rooms, threads, bots, reactions, and more.

Apron decouples chat clients from servers: use an existing client with your own backend, or build a new client for existing Apron servers.

Use it for a self-hosted group chat, an agent interface, or a bridge to another service. The server is trusted with identity, membership, and history. Leaving out public federation and end-to-end encryption keeps custom implementations small.

1.The Protocol

JSON over any transport, like WebSocket. Small core specification and optional incremental capabilities with graceful fallbacks.

{"method": "server", "params": {"apron": {{version}}, "auth": ["guest"]}}
{"method": "auth", "id": "c1", "params": {"scheme": "guest", "name": "Ada"}}
{"id": "c1", "result": {"you": {"user_id": "guest_1234", "name": "Ada"}}}
{"method": "message", "id": "c2", "params": {"body": {"text": "Hello"}}}
{"method": "message", "params": {"room_id": "general", "from": {"user_id": "guest_1234"}, ...}}
{"id": "c2", "result": {"message_id": "1724803200042"}}
